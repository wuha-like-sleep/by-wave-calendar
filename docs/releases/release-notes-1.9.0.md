# 服务端 1.9.0 · 桌面端 1.3.0 · Android 0.13.0 · iOS 1.8.0

## 日历同步与删除响应

ByWave 的日程创建、修改和删除提交后，会立即把对应 Outlook 日历加入持久化同步队列。同进程合并唤醒等待约 250 毫秒，跨进程队列每 5 秒检查一次；空闲的 Outlook 同步周期缩短至 30 秒。请求限流、网络故障仍保留退避，暂停的同步不会因编辑日程而自动恢复。

删除优先于批量导入和编辑。Outlook 中消失的日程采用最多 3 个并发请求逐项确认，缩短批量删除检查时间；任一检查失败时整轮停止，不把网络错误当成删除。超过单批 100 项的任务会继续排队，避免一批大量日程阻塞后续删除。旧任务完成时不会覆盖执行期间的新修改请求，重复删除不会重复发出取消通知。冲突处理必须与当前两端版本匹配，过期的选择会要求重新查看。

桌面端和手机端在前台每 15 秒刷新日程，回到前台时立即刷新，避免服务器已经同步但 App 仍显示旧内容。操作系统日历和 Outlook 自身的刷新节奏仍由对应客户端控制，不能保证端到端固定时限。

## App 内设置

Windows、macOS、Android 和 iOS 均可在设置中连接 Outlook、选择日历、管理同步关系、手动同步、暂停、恢复和处理冲突。Microsoft 授权仍在官方授权页完成。Mac 可以在 App 中选择 CalDAV 日历、创建专用密码和安装系统账户描述文件；最后的账户安装由 macOS 确认。

手机本机日历镜像增加选择日历、暂停和移除入口。该本机镜像仍是 ByWave 到系统日历的单向副本；需要双向同步时使用 Outlook 连接。Mac CalDAV 和 Outlook 连接支持双向同步。

桌面设置按旧版核对，保留账号、日历、预约、安全、设备、提醒、语言、外观和关于功能；提醒、语言、设备独立为可直接访问的分类。修复旧版设置深链接，旧的 Passkey、MFA、外观和账号操作链接可以跳到现行页面。统一已确认的品牌图标，调整侧栏、工具栏、月历导航、设置滚动和页面切换动画。

## 手机登录与更新

网页登录增加 PKCE、随机状态、一次性短时授权码和严格回调校验。Android 待授权信息加密保存，支持浏览器返回时恢复；iOS 支持取消与授权超时。网页授权确认保留 CSRF、账号和 MFA 检查。

Android 更新在下载和安装前核对 HTTPS、文件大小、SHA-256、包名、递增版本号和应用签名，支持取消和重试，安装仍由系统确认。iOS 增加版本检查与 App Store / TestFlight 入口，安装由 Apple 分发渠道处理。

## 升级与验证

数据库迁移 `0061_native_calendar_access.sql` 增加应用密码的日历范围、暂停状态，以及同步请求版本计数；旧密码保留原有全部日历访问范围。客户端新功能需要服务端 1.9.0。

本次服务端、Windows、macOS 和 Android 安装包均在本机构建，并发布至 GitHub 与 Gitee；GitHub Actions 保持停用。桌面更新清单为 1.3.0（27），Android 更新清单为 0.13.0（23），均包含实际文件大小和 SHA-256。Mac Apple Silicon / Intel 安装包已签名、公证并附带公证票据；Windows 安装器尚未签名，会显示未验证发布者。Android 使用与 0.12.1 相同的发布证书，已在独立 Android 15 模拟器完成覆盖升级和启动检查，并修复登录与更新页面加载自适应图标导致的启动崩溃。

Windows 在本地 Windows 11 虚拟机验证旧版升级、全新安装、卸载、特殊路径和资料保留。新的压缩安装包减少下载体积。iOS 1.8.0 本次仅发布源码并完成模拟器编译，尚未提交 App Store / TestFlight；Linux 未发布新安装包。

本地验证覆盖服务端类型检查、1,328 项单元测试、625 项集成测试、八语言完整性、桌面和 Android 回归测试，以及 iOS 模拟器编译与网页登录证明校验。真实 Microsoft 账号授权、手机真机日历权限及分发升级仍需在实际账号和设备上验收。
