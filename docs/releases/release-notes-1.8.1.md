# 服务端 1.8.1

平台管理员可以在「管理后台 → 系统日历配置」填写 Microsoft 应用的 Client ID。
保存后后台状态、用户 Outlook 连接入口和之后发起的授权同步读取新配置，无需重启服务器。
已经打开的连接页会在返回标签页时检查配置，可见时每 30 秒检查一次，并保留正在填写的日历选择。

后台填写优先于环境变量。清空并保存可暂停新连接，也可恢复使用环境变量。
既有账号继续使用原来的应用凭据；更换平台配置不会删除现有同步关系或日历数据。
配置修改要求管理员会话、MFA（启用时）和 CSRF 验证，并记录审计日志。

包含可重复执行的数据库迁移 `0060_microsoft_calendar_config.sql`，旧环境变量配置会自动保留。
详细说明见[系统日历配置](../system-calendar-sync.md)。
