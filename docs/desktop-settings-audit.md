# 桌面设置核对

对照旧版 `05229c7` 与 1.8.1 主线，设置入口按以下方式保留。旧页面中已有的账号及安全操作不因视觉调整删除。

| 原有功能 | 当前入口 |
| --- | --- |
| 账号资料、头像、账号切换和退出 | 账号 |
| 日历创建、编辑、删除、分享与订阅 | 日历 |
| Outlook 双向同步、Mac CalDAV 账户 | 系统日历 |
| 预约链接管理 | 预约 |
| 密码、Passkey、MFA、登录方式和账号删除 | 安全；需要网页验证的操作进入对应安全页面 |
| 设备与会话管理 | 设备 |
| 提醒开关及桌面提醒 | 提醒 |
| 界面语言 | 语言 |
| 主题、周起始日和显示偏好 | 外观 |
| 版本、更新、法律文档 | 关于 |

设置内容区保留可见滚动条，切换账号或分类时复位滚动位置。主界面侧栏日历开关可以控制显示，小月历提供日期和月份导航。

旧的 `/app/settings#passkey`、`#mfa`、`#theme` 等地址通过本地白名单映射到现行分类页面，兼容旧客户端。跳转丢弃查询参数，仅接受已知设置页面与锚点，避免把旧链接变成开放重定向。

验收使用本地独立预览账户与示例日程，检查主日历、账号、安全、语言和提醒页面；预览不修改真实账户数据。
